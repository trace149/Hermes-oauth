Privacy Policy

Last updated: November 4, 2026

Hermes Local Assistant (“the app”) is a personal assistant I run on my own computer. It accesses Google user data only after I sign in with Google and only for the scopes I approve.

Data the app accesses

  • Google Calendar data (events, calendars, availability) when Calendar access is authorized
  • Other Google Workspace data only if I later authorize additional scopes (for example Gmail or Drive)

How data is used

Google user data is used solely to power features I request in the local Hermes assistant (for example listing, creating, updating, or deleting calendar events). Data is not sold, not used for advertising, and not used to train models for other people.

How data is stored

OAuth tokens are stored locally on my computer (for example under ~/.hermes/) so the app can refresh access without asking me to sign in every time. Calendar content may appear briefly in local logs or chat history on that same machine while I use the assistant.

Sharing

Google user data is not shared with third parties, except Google itself through official APIs when the app makes requests on my behalf.

Retention and deletion

I can revoke access at any time in Google Account permissions and by deleting local token files on my computer. After revocation, the app can no longer access my Google data.

Contact

This app is for personal use. Questions about this policy can be directed to the Google account email used to authorize the app.
